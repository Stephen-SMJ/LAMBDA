# LAMBDA PowerPoint Skill

Use this skill when the user asks for a PPT, PowerPoint, presentation, slide deck, executive deck, or wants a report converted into slides.

## Default Output

Create an editable PowerPoint file with `python-pptx`.

- Save the final file as `slides.pptx` in the current working directory.
- `python-pptx` is preinstalled in the local workspace.
- Do not use LaTeX Beamer unless the user explicitly asks for PDF slides.
- Do not install packages unless `import pptx` fails. If installation is essential, use exactly:
  `/opt/python/versions/cpython-3.11.14-linux-x86_64-gnu/bin/python3 -m pip install python-pptx --break-system-packages --no-cache-dir`
- Do not use `apt-get`, `sudo`, `pip3`, shell chaining, pipes, or redirection.

## Required Workflow

1. If the deck needs more than five meaningful steps, call `update_todo` first.
2. Inspect the current working directory for existing report files and figures.
3. If a report exists, use it as the storyline. If not, create the storyline from analysis results.
4. Include every important generated figure. If there are many figures, put weaker figures in appendix slides.
5. Use one central message per slide. Avoid dense bullet lists.
6. Save `slides.pptx`.
7. Verify it with `ls -lh slides.pptx`.

## Visual Style

Use a clean modern data-presentation layout:

- 16:9 widescreen.
- Blue header band at the top.
- Light gray body background.
- White chart panel on the left.
- White insight card on the right.
- Large readable titles and bullets.
- Three to four insight bullets per slide.
- Full-size charts with labels and legends preserved.
- If the UI language preference is Chinese, write titles and insights in Chinese.

The standard figure slide should use this structure:

- Top 15%: solid blue title band.
- Left 62% of body: figure inside a white panel.
- Right 32% of body: white card titled `Key Finding` or `关键发现`.
- Bottom: subtle footer only.

## Slide Plan

Use this sequence unless the user asks otherwise:

1. Cover slide.
2. What matters most: 3 to 5 quantified takeaways.
3. Data context: rows, fields, time span, scope, limitations.
4. Figure-driven insight slides.
5. Segment/comparison slides.
6. Method/model slide if modeling was used.
7. Recommendations and next checks.
8. Appendix for remaining useful figures.

## Recommended Template

Adapt this code. Replace placeholder text with real findings and numbers.

```python
from pathlib import Path
from datetime import date
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN, MSO_AUTO_SIZE
from pptx.enum.shapes import MSO_SHAPE

WORK = Path("./data/workspaces/<conversation_id>")
OUT = WORK / "slides.pptx"

prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.5)
W, H = prs.slide_width, prs.slide_height

COLORS = {
    "blue": RGBColor(37, 99, 235),
    "bg": RGBColor(244, 246, 248),
    "white": RGBColor(255, 255, 255),
    "ink": RGBColor(20, 24, 33),
    "muted": RGBColor(83, 91, 105),
    "line": RGBColor(225, 229, 235),
}

FONT = "Aptos"
CJK_FONT = "Noto Sans CJK SC"

def fill(shape, color):
    shape.fill.solid()
    shape.fill.fore_color.rgb = color
    shape.line.fill.background()

def blank_slide():
    slide = prs.slides.add_slide(prs.slide_layouts[6])
    slide.background.fill.solid()
    slide.background.fill.fore_color.rgb = COLORS["bg"]
    return slide

def add_text(slide, text, x, y, w, h, size=22, bold=False, color="ink", align=None, font=FONT):
    box = slide.shapes.add_textbox(Inches(x), Inches(y), Inches(w), Inches(h))
    tf = box.text_frame
    tf.clear()
    tf.word_wrap = True
    tf.auto_size = MSO_AUTO_SIZE.TEXT_TO_FIT_SHAPE
    p = tf.paragraphs[0]
    p.text = text
    p.font.name = font
    p.font.size = Pt(size)
    p.font.bold = bold
    p.font.color.rgb = COLORS[color]
    if align:
        p.alignment = align
    return box

def add_bullet(slide, text, x, y, w, h, size=18, color="ink", font=FONT):
    box = slide.shapes.add_textbox(Inches(x), Inches(y), Inches(w), Inches(h))
    tf = box.text_frame
    tf.clear()
    tf.word_wrap = True
    tf.auto_size = MSO_AUTO_SIZE.TEXT_TO_FIT_SHAPE
    p = tf.paragraphs[0]
    p.text = "• " + text
    p.font.name = font
    p.font.size = Pt(size)
    p.font.color.rgb = COLORS[color]
    p.line_spacing = 1.05
    return box

def add_header(slide, title):
    header = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, Inches(0), Inches(0), W, Inches(1.15))
    fill(header, COLORS["blue"])
    add_text(slide, title, 0.7, 0.24, 11.9, 0.62, size=32, bold=True, color="white", font=CJK_FONT)

def add_footer(slide, page=None):
    add_text(slide, "Generated by LAMBDA · https://lambda.com.ai", 0.65, 7.12, 6.2, 0.2, size=7, color="muted")
    if page is not None:
        add_text(slide, str(page), 12.25, 7.12, 0.45, 0.2, size=7, color="muted", align=PP_ALIGN.RIGHT)

def add_panel(slide, x, y, w, h, color="white"):
    panel = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, Inches(x), Inches(y), Inches(w), Inches(h))
    panel.fill.solid()
    panel.fill.fore_color.rgb = COLORS[color]
    panel.line.color.rgb = COLORS["line"]
    return panel

def fit_picture(slide, image_path, x, y, w, h):
    pic = slide.shapes.add_picture(str(image_path), Inches(x), Inches(y))
    max_w, max_h = Inches(w), Inches(h)
    scale = min(max_w / pic.width, max_h / pic.height)
    pic.width = int(pic.width * scale)
    pic.height = int(pic.height * scale)
    pic.left = Inches(x) + int((max_w - pic.width) / 2)
    pic.top = Inches(y) + int((max_h - pic.height) / 2)
    return pic

def add_cover(title, subtitle):
    slide = blank_slide()
    add_header(slide, title)
    add_text(slide, subtitle, 0.9, 2.35, 9.2, 0.8, size=22, color="ink", font=CJK_FONT)
    accent = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, Inches(0.9), Inches(3.35), Inches(2.8), Inches(0.08))
    fill(accent, COLORS["blue"])
    add_text(slide, "LAMBDA", 0.9, 6.35, 2.3, 0.35, size=15, bold=True, color="blue")
    add_text(slide, str(date.today()), 10.0, 6.35, 2.3, 0.3, size=11, color="muted", align=PP_ALIGN.RIGHT)
    return slide

def add_summary_slide(title, bullets, page):
    slide = blank_slide()
    add_header(slide, title)
    add_panel(slide, 0.8, 1.65, 11.75, 4.8)
    y = 2.05
    for bullet in bullets[:5]:
        add_bullet(slide, bullet, 1.25, y, 10.8, 0.62, size=22, font=CJK_FONT)
        y += 0.78
    add_footer(slide, page)
    return slide

def add_figure_slide(title, image_path, bullets, page, heading="Key Finding"):
    slide = blank_slide()
    add_header(slide, title)
    add_panel(slide, 0.35, 1.45, 8.05, 4.75)
    fit_picture(slide, image_path, 0.55, 1.62, 7.65, 4.38)
    add_panel(slide, 8.72, 1.65, 3.95, 4.55)
    add_text(slide, heading, 9.08, 2.02, 3.25, 0.42, size=23, bold=True, color="blue", font=CJK_FONT)
    y = 2.72
    for bullet in bullets[:4]:
        add_bullet(slide, bullet, 9.08, y, 3.15, 0.72, size=19, font=CJK_FONT)
        y += 0.82
    add_footer(slide, page)
    return slide

figures = []
for ext in ("*.png", "*.jpg", "*.jpeg", "*.webp"):
    figures.extend(sorted(WORK.glob(ext)))

add_cover(
    "Specific Data Story Title",
    "A concise slide deck that turns the analysis into evidence, implications, and next actions."
)

page = 2
add_summary_slide("What matters most", [
    "Replace this with a quantified insight from the analysis.",
    "Explain which group, period, or variable drives the result.",
    "State the decision or follow-up analysis implied by this result.",
], page)
page += 1

for fig in figures:
    title = fig.stem.replace("_", " ").replace("-", " ").title()
    add_figure_slide(title, fig, [
        "Describe the visible pattern using concrete numbers.",
        "Explain why this chart matters for the user question.",
        "Mention any caveat or next check if confidence is limited.",
    ], page)
    page += 1

add_summary_slide("Recommendations and next checks", [
    "Prioritize the strongest finding and validate it with additional data.",
    "Check outliers, missingness, and segment stability before operational use.",
    "Turn the highest-confidence insight into the next analysis or action.",
], page)

prs.save(OUT)
print(f"Saved {OUT}")
```

Then verify:

```bash
ls -lh ./data/workspaces/<conversation_id>/slides.pptx
```

## Quality Rules

- Do not make every slide a bullet list.
- Do not use tiny charts or crop axis labels.
- Do not dump all figures on one slide.
- Use appendix slides for secondary figures.
- If a chart is unreadable, regenerate the chart before adding it.
- If converting from a PDF or LaTeX report, map each major section to one or more slides, then add the figures that support that section.
